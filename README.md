# WebinarForge — ressources pratiques pour préparer et promouvoir vos webinaires

Je développe [WebinarForge](https://webinar-forge.com/), un outil destiné aux entrepreneurs, coachs, consultants et formateurs qui souhaitent organiser la préparation de leurs webinaires et de leurs contenus marketing.

## La bibliothèque de guides gratuits

Une mini-bibliothèque responsive est préparée dans le dossier `docs/`. Après activation de GitHub Pages, elle sera accessible à l'adresse **https://hsergo.github.io/**.

- [Préparer un webinaire pour vendre une formation ou un service](docs/articles/preparer-webinaire-vendre-formation.html)
- [Checklist de lancement : de l'idée à la promotion](docs/articles/checklist-lancement-webinaire.html)
- [Promouvoir un webinaire et attirer des participants qualifiés](docs/articles/promouvoir-webinaire-participants-qualifies.html)

Les versions Markdown éditables restent disponibles dans [content/marketing](content/marketing/).

## Activer la publication du mini-site

La création des fichiers ne suffit pas à rendre le site public sur le Web. Pour publier la bibliothèque :

1. Ouvrir les [paramètres du dépôt](https://github.com/Hsergo/Hsergo/settings/pages).
2. Dans **Build and deployment**, choisir **Deploy from a branch**.
3. Sélectionner la branche **main** et le dossier **/docs**.
4. Cliquer sur **Save**, puis attendre la fin du déploiement.
5. Vérifier l'adresse proposée par GitHub Pages et ouvrir les trois guides sur ordinateur et mobile.

Si GitHub affiche un domaine différent, utiliser l'URL indiquée dans les paramètres plutôt que de supposer que la publication a réussi.
